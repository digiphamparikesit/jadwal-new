1 Hak Akses & Login
Aplikasi memiliki 2 level pengguna dengan hak akses berbeda.

Staff (Tanpa Login)

Dapat mengakses tanpa perlu login:

  • Form Pengajuan — kirim izin, sakit, cuti, tukar shift
  • Rekap Jadwal — lihat siapa bertugas per ruangan
  • Jadwal Lengkap — grid jadwal bulanan

Admin (Perlu Login)

Login dengan email & password yang sudah terdaftar:

  1. Klik ikon user di kiri bawah sidebar, atau tombol Mode Edit di kanan atas
  2. Masukkan email dan password admin
  3. Klik Masuk
  4. Menu admin akan muncul di sidebar (Dashboard, Master Data, dll)
Tips: Centang "ingat saya" (jika tersedia) agar tidak perlu login berulang kali. Sesi tersimpan di browser.
2 Fitur untuk Staff
Fitur yang dapat diakses tanpa login.

Form Pengajuan

Mengajukan izin, sakit, cuti, telat, atau tukar shift. Jadwal akan otomatis terupdate setelah pengajuan dikirim.

  1. Pilih nama Anda dari dropdown
  2. Pilih Jenis Pengajuan (Izin / Sakit / Cuti / Telat / Absensi Eror / Tukar Shift)
  3. Isi tanggal dan detail yang diminta
  4. Tambahkan keterangan (opsional)
  5. Klik Kirim Pengajuan
Otomatis: Pengajuan Izin/Sakit/Cuti akan langsung mengubah jadwal Anda di bulan terkait dengan kode IZIN / SKT / CT.

Rekap Jadwal per Ruangan

  1. Pilih tanggal dengan klik tombol panah atau date picker
  2. Lihat kartu ruangan — klik untuk expand daftar staff bertugas
  3. Ikon ★ menandakan koordinator ruangan
  4. Bagian bawah menampilkan ringkasan staff yang libur/cuti/sakit

Jadwal Lengkap

Grid bulanan semua staff dengan kode shift per hari.

  • Ganti bulan/tahun dengan tombol panah atau dropdown
  • Gunakan filter: kategori (SHIFT/NON-SHIFT), ruangan, status
  • Ketik di kolom pencarian untuk filter nama staff
  • Kode warna mewakili jenis shift (lihat Bagian 5)
3 Fitur untuk Admin
Fitur khusus admin — perlu login terlebih dahulu.

Dashboard Analytics

Analitik lengkap: KPI, tren, peringkat kehadiran, heatmap, dan lainnya.

  • Filter tahun/bulan di toolbar atas
  • Klik grafik untuk membuka mode fullscreen (popup besar)
  • Tekan ESC atau klik area luar untuk menutup popup
  • Klik Export PDF untuk menyimpan laporan dashboard

Rekap Jam Kerja

  1. Pilih tahun dengan panah atas/bawah
  2. Atur rentang tanggal (mulai - akhir) lalu klik Muat
  3. Klik nama staff untuk lihat detail per bulan
  4. Klik ikon printer untuk cetak PDF laporan per staff

Rekap Kehadiran

  1. Atur periode (tanggal mulai - akhir)
  2. Klik Muat
  3. Klik nama staff untuk detail ketidakhadiran per tanggal
  4. Klik Matrix Bulanan untuk melihat % kehadiran setahun penuh
  5. Klik Cetak PDF untuk laporan per staff atau semua staff

Master Data Staff

  1. Klik Tambah Staff untuk input data baru
  2. Isi: NIP, Nama, Jabatan, Departemen, Tanggal Lahir, dll
  3. Umur & masa kerja akan dihitung otomatis
  4. Klik ikon pensil untuk edit, jam pasir untuk lihat riwayat, tong sampah untuk hapus

Riwayat Penempatan

  1. Klik Tambah Penempatan untuk input satu per satu
  2. Klik Import Penempatan untuk bulk input dari Excel
  3. Filter berdasarkan ruangan, peran, atau status (aktif/selesai)
Peran yang didukung: Kepala Instalasi, Koordinator, Staff, PIC, Magang, Lainnya.

Mode Edit (Jadwal)

  1. Login sebagai admin
  2. Klik tombol Mode Edit di kanan atas
  3. Anda akan diarahkan ke menu Jadwal Lengkap
  4. Setiap sel jadwal berubah menjadi dropdown — pilih kode baru
  5. Perubahan tersimpan otomatis ke database
  6. Klik Keluar Edit untuk menonaktifkan mode edit
4 Import Data dari Excel
Bulk input data dari file Excel tanpa perlu input manual satu per satu.

Import Jadwal (Bulan Baru)

  1. Buka file Excel jadwal bulanan
  2. Blok semua data → Ctrl+C
  3. Buka menu Import Jadwal → Paste (Ctrl+V) di kotak besar
  4. Klik Preview untuk melihat ringkasan
  5. Periksa warning/error jika ada
  6. Klik Import ke Database
Format header tanggal yang didukung: 1 Oktober 2026, 1-Okt-2026, 01/10/2026, atau 2026-10-01.

5 Kode Shift & Formula
Daftar kode shift yang digunakan dalam jadwal.

Formula % Kehadiran

Piket = P + TS + S + M
Non-Hadir = IZIN + SKT + DL + CT + CM
Hari Kerja Wajib = Piket + Non-Hadir
% Kehadiran = (Piket ÷ Hari Kerja Wajib) × 100%
RentangKategori
≥ 95%Sangat baik
80% – 94%Cukup
< 80%Perlu perhatian
6 Tips & Trik
Fitur tersembunyi dan shortcut yang mempercepat pekerjaan.

⌨️ Keyboard Shortcut

  • ESC — Tutup semua modal yang sedang terbuka
  • Ctrl + F5 — Hard refresh (bersihkan cache)
  • F12 — Buka Console untuk debugging

🎯 Interaksi Cepat

  • Klik kartu ruangan di Rekap Jadwal untuk expand/collapse
  • Klik grafik di Dashboard untuk mode fullscreen
  • Klik nama staff di tabel untuk lihat detail
  • Klik ikon printer untuk cetak laporan PDF per staff

🔍 Pencarian Global

Kotak pencarian di kanan atas berfungsi multi-tab:

  • Mengetik akan otomatis memfilter tabel di tab aktif
  • Bekerja di: Jadwal, Jam Kerja, Kehadiran, Pengajuan
7 Pertanyaan Umum (FAQ)
Jawaban untuk pertanyaan yang sering ditanyakan.
Data tidak muncul / kosong?
Kemungkinan penyebab:
  • Belum login sebagai admin (menu tertentu terkunci)
  • Tanggal/periode yang dipilih tidak memiliki data
  • Buka Console (F12) untuk melihat error yang muncul
Kenapa pengajuan saya tidak muncul di jadwal?
Cek beberapa hal:
  • Pastikan NIP Anda sudah terdaftar di Master Data Staff
  • Cek apakah nama di jadwal berbeda dengan nama lengkap (bisa berbeda)
  • Hubungi admin untuk verifikasi
Bagaimana cara tukar shift dengan rekan?
Isi form Tukar Shift:
  • Pilih nama Anda
  • Pilih jenis: Tukar Shift
  • Isi tanggal tukar
  • Pilih nama rekan pengganti
  • Sistem akan menampilkan preview pertukaran shift
  • Klik Kirim
Bagaimana cara ganti label kode shift (P, TS, S, M)?
Login sebagai admin → buka Pengaturan (sidebar bawah) → bagian Label Kode Jadwal → ubah teks → Simpan. Label akan berubah di semua tampilan.
Bagaimana cara mengatur jam kerja per ruangan?
Login admin → Pengaturan → bagian Jam Kerja per Ruangan → isi jam untuk tiap kode (P/TS/S/M) di masing-masing ruangan → Simpan. Nilai ini diprioritaskan di atas jam global.
Grafik tidak rata / tampilan aneh?
Coba:
  • Ctrl + F5 untuk hard refresh
  • Perbesar jendela browser (minimal 900px lebar)
  • Reset zoom browser (Ctrl + 0)
  • Gunakan browser modern (Chrome/Edge/Firefox terbaru)
Apakah data otomatis tersimpan?
Ya. Semua perubahan (edit jadwal, tambah staff, import, dll) langsung tersimpan ke database Supabase. Tidak ada tombol "Save" terpisah.
Bagaimana cara export laporan ke PDF?
Di menu yang menyediakan tombol Cetak PDF:
  • Rekap Jam Kerja — cetak per staff atau semua staff
  • Rekap Kehadiran — cetak per staff atau semua staff
  • Matrix Bulanan — cetak tabel matrix % kehadiran
  • Dashboard — export seluruh dashboard
Siapa yang bisa mengakses menu admin?
Hanya user yang email-nya terdaftar di tabel admin_users. Jika login berhasil tapi menu admin tidak muncul, hubungi pengembang untuk mendaftarkan akun Anda.
